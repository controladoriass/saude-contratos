# Saúde dos Contratos — Silva & Silva Advogados

Painel de acompanhamento do banco de horas dos clientes contratados.
Um farol por cliente indica, por projeção de consumo, se o contrato caminha
para dentro ou para fora do banco de horas, com recomendação de aditivo
explicada em números.

- Faróis: **vermelho** (estourou / projeta estourar → aditivo), **amarelo**
  (projeta fechar entre 80% e 100% → monitorar), **verde** (projeta < 80%).
- Universal para contratos mensais, trimestrais, semestrais e anuais.
- Dados gerados a partir dos relatórios de horas semanais de cada cliente.

Uso interno. Atualização: consolidação semanal (segunda-feira).
